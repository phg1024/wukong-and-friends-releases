# Wukong & Friends — PDFs and reader images

Free illustrated stories in English and Simplified Chinese. Read online at https://phg1024.github.io/wukong-and-friends/

Each published edition of each book has its own release here: the reading PDF (for screens) and the print-booklet PDF
(print on both sides, fold into a book), in English and Chinese, with a note on what changed in that edition. File
bytes are never overwritten; a new edition gets a new release. Older shared links keep working from the historical
[pdf-library-v1](https://github.com/phg1024/wukong-and-friends-releases/releases/tag/pdf-library-v1) archive.
